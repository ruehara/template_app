# Lottie Animations

Adicione aqui arquivos `.json` exportados do [LottieFiles](https://lottiefiles.com).

## Arquivos esperados pela LottiesPage

| Arquivo | Descrição |
|---------|-----------|
| `loading.json` | Animação de carregamento |
| `success.json` | Animação de sucesso |
| `error.json` | Animação de erro |

Se os arquivos não existirem, a página mostra uma instrução de fallback.
